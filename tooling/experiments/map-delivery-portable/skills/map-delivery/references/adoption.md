# 项目接入

在首次建立地图、选择文档工作树或定位失败时读取本文件。

## 确定文档位置

先检查项目的 `AGENTS.md`、README、现有业务地图及相关配置。以稳定业务能力组织模块，保持实现仓库与能力的关系可查；一个模块可以涉及多个仓库，一个仓库也可以实现多个模块。

已有地图时沿用其入口、命名和语言。脚本返回的默认路径只是一项定位结果；它没有发现 `map/`，不代表项目没有规格。检查已知文档入口后，明确使用现有路径，或指出尚缺定位信息。目录损坏、显式路径不存在或配置非法时报告原始问题，避免静默改用另一份文档。

可选配置放在项目根 `.map-delivery.json`：

```json
{
  "schema_version": 1,
  "docs_root": ".",
  "map_root": "docs/map",
  "language": "zh-CN"
}
```

`docs_root` 相对项目根解析，默认为 `.`；`map_root` 相对文档根解析，默认为 `map`。`language` 是可选的自然语言偏好，省略时沿用项目。配置仅描述位置与语言，不定义审批、生命周期或执行权限。

仓内 `docs/map` 可使用上面的配置。独立文档仓可把 `docs_root` 指向已选本地文档工作树，并使用 `map_root: "map"`。首次接入时，将用户选定的非默认位置保存为项目配置，或接入已经存在的项目根导航，让新会话可以恢复定位。临时查看另一文档工作树时显式传入 `--docs-root`，保持地图路径相对该工作树解析；临时选择不修改已保存的默认位置。

```bash
python3 <skill-dir>/scripts/context.py \
  --project-root <project> \
  --docs-root <selected-docs-worktree> \
  --json
```

定位成功后读取文档根及目标目录的约定。脚本观察到的本地提交只说明所在检出的状态；工作区有改动时，提交标识不足以代表候选全部内容，交接还需记录改动范围或可复现补丁。

完成条件：已选定唯一的文档工作树、地图位置、适用规则和语言；任何无法确定的项都有具体说明。

## 首次建立地图

用户要求接入这种模式后，从本次授权范围内的一个业务能力开始，避免先生成全公司空目录。通过需求、当前代码和现有材料辨认模块职责、共享接口及相邻能力；代码中观察到的行为与已确认需求分别标明。

若项目没有现成结构，可采用：

```text
<map-root>/
  README.md
  <业务域>/
    <模块>/
      README.md
      spec.md
      changes/
        <stable-id>/
          change.md
```

地图入口记录模块链接和一句话职责；模块入口记录规格权威状态、代码位置、共享契约和实际 Change。目录名按项目习惯，英文或其他语言均可。初始化时只创建需要的文件，不为尚未发生的审查或验证预填结论。

模块是新能力时，先起草完整初版规格，在入口明确“拟议 / 尚未实施”以及待确认事项，再制定首次实施 Change。既有能力缺规格时，按授权整理现有事实和未决需求；普通开发请求本身不意味着可以把它改名为新模块或宣布基线已确认。已足够明确的范围可以继续起草候选，缺少的需求按具体问题提出。

完成条件：从项目根可以发现选定地图并定位本次模块；规格说明覆盖与缺口；读者能识别哪些是现行约定、观察结果或候选方案。用新会话会采用的项目入口或定位命令再检查一次，不能只从当前会话已知的地图路径进入。

## 适配现有项目

本 Skill 不要求替换原目录或迁移全部旧文档。已有完整规范体系时，建立业务入口与权威文档的导航即可，避免产生第二份相同权威的规格。

| 项目差异 | 适配方式 |
| --- | --- |
| GitHub、GitLab、Gitee 或其他平台 | 按项目要求关联真实 Issue/PR/MR；公共流程不依赖某个平台 |
| 无远端 Issue | 采用模块内或项目内唯一的稳定 Change ID，保留更名与拆分关系 |
| 独立文档仓、多实现仓 | 明确各仓库职责，逐仓记录候选修订和依赖 |
| 要求独立 Hub、Plan、Review、Evidence | 沿用这些文件与项目门禁，将本 Skill 的场景和追溯写入现有位置 |
| 已有校验器或 CI | 使用实际命令与结果，保留其更严格要求 |
| 不使用 Git | 采用项目可解析、可复现的修订标识及内容快照 |

文档语言和平台适配不改变事实标准：不存在的链接留空并说明，未核实的远端状态标记未核实。需要安装、发布、平台写入或更改审批边界时按用户授权范围执行，接入地图本身不附带这些权限。
