# 机器检查清单

此目录供知识与公开边界检查工具使用，不是业务规格入口。

- `HISTORICAL_REFERENCES.json`：逐文件历史引用及内容摘要；未登记文件和活动源码继续接受检查。
- `PUBLICATION_POLICY.json`、`SCAN_EXCEPTIONS.json`：公开范围、保留声明和逐内容扫描例外。
- 其余来源与转换清单：保留迁移来源、路径及经过审查的转换记录。

当前文档的正文归属和有效状态见 [文档来源索引](../../docs/index.yaml)。公开范围说明见 [迁移记录](../../docs/changelog/2026-10-15-public-scope.md)。更改清单应与对应来源、验证和复审一起提交；不能只为使检查变绿而扩大例外。
