## LoopX 边界

独立只读复审核实：当前版本 `connect/bootstrap` 对 SQLite canonical Goal 要求保持原注册项目和状态路径；`migrate-state` 执行阶段受 legacy writer fence 保护；`refresh-state --project` 只改变本次路径解析，`sync-global --replace-state` 只同步已有合法 Registry。它们都不是受支持的 canonical 路径迁移接口。

因此采用 [新入口转发](../runbook/daily-development.md)，保留同一 SQLite Goal 和原注册位置。未手工改 Registry、未绕过 fence、未创建第二个数据库。完整 M5 的“注册位置迁出旧目录”条件仍未满足，等待正式接口支持；不需要重新请求已经获得的迁移许可。
