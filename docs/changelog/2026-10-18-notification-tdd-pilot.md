## 缺陷与先红后绿

正文 `由 张三 手动触发\r\n设备已联动` 已有完整触发人首行，旧实现只识别 LF，误加一行；旧账号首行也无法被移除。修复只识别完整的 LF/CRLF 首行，不整体转换正文换行、不循环清理重复行。名称优先级、规则场景发送条件保持不变。

从仓库根可运行：

```bash
go -C backend/saas test ./service/syssvr/internal/logic/notifymanage -run '^TestTriggerBodyCompleteLinesWithCRLF$' -count=1 -v
```
