# ai-native 团队 AI 配置仓库

- `skills/` 保存可分发技能，`rules/` 保存团队规则；业务规格和交付记录留在对应研发文档仓。
- 使用 `skills/map-delivery` 作为唯一团队源码（`canonical`）。排查来源迁移、注册或宿主发现时，读取 [验证记录](docs/validation.md)；接入成员或调整 TeamAI 时，读取 [接入步骤](docs/teamai.md)。
- 修改技能时保留项目现有授权、精确 Head 和校验边界；通过代码解析文档仓，不依赖技能安装路径推断文档仓。
- 提交前运行 README 中的仓库验证命令。生成的安装链接、缓存、个人配置和试点结果放在忽略目录。
- 第三方分发工具版本固定。团队远端写入和真实宿主初始化与隔离试点分别验证。
