# 探索态
一个proposal，如果只想明白30%，AI能够很快帮你补齐剩下地70%，而且补得有结构、有观点、有方案，看起来特别棒。但这恰恰是最危险的地方，你觉得它说的有道理，但又总觉得哪里不对。往往会改prompt继续追问，继续让它优化，最后文档越来越长，方案越来越复杂，模糊反而扩大了，人也懵了，我一开始到底想解决什么问题，解决到什么程度。
这不是AI做错了，而是proposal不是执行态，而应该是探索态。
当事情我们没有想明白时，我们绝对不能对AI说：帮我做个方案。相反的，我们要告诉AI，这件事情我还没有想透，先别给我方案，帮我把问题拆开，告诉我有哪些关键决策我必须自己做。甚至让AI不断地提问自己，直到我们把目标、边界和核心矛盾说清楚。这时的AI不是执行者，而是陪我们对练的教练。它的任务不是替我们往前跑，而是把我们脑子里的漏洞一个个逼出来。
探索态要做到什么程度才算成功？
1.解决什么问题？
2.为什么做？
3.哪些不做
4.做到什么程度才算合格

# 这个阶段使用什么工具？
grill-me: 是一个无状态的需求澄清工具。只通过对话“拷问”你，不读写任何文件，适合在想法还很模糊时使用。

grill-with-docs: 是 grill-me 的有状态版本。它会在访谈过程中读取你的代码、文档，并将澄清后的决策、术语沉淀为 CONTEXT.md、ADR 等文档。
