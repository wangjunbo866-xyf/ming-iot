OpenViking
参考OpenViking社区[开放维京特工] 的模式：
飞书长连接的事件由 lark-daemon 接（Node/JS），它管会话、策略和投递，把消息交给运行时的 agent（pi，MIT，read/bash/edit/write + session + hook），长期记忆和跨会话上下文放在 OV 里，模型走外部 API。区别是 VikingBot 自己是面向人的对话 agent，[开放维京特工] 更像是「挂在宿主运行时上的一个群成员」，主要工作是查代码 / 文档并回帖。
