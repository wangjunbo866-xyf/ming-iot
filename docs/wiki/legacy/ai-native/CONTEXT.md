# AI Native 团队协作

本词表记录团队讨论中已确认的概念。工具选型、运行规则和未决问题另行记录。

## Language

**个人记忆**：成员私有的工作经验与上下文；其中的信息只有经过本人或责任人确认，才能成为团队共享知识。
_Avoid_：默认共享的个人历史

**团队记忆**：经本人或责任人确认后，可供团队复用的知识与经验。
_Avoid_：全员原始会话汇总

**薄导航**：从业务能力通往权威规格、实现和相关知识的简短索引，只记录必要边界与引用关系。
_Avoid_：另行维护的规格或任务正文

**业务地图**：以业务域和功能为主阅读视角，将一个功能的规格与跨仓实现、相关知识连接起来的导航。
_Avoid_：仅按代码仓划分的功能清单

**需求验收人（P）**：对一条需求的业务范围、行为语义和最终业务验收负责的成员。

**交付责任人（D）**：对一条需求从实现到可复验交付的完整性负责的成员。

**独立评审人（R）**：与该需求交付责任人分离、对最终 PR 审查负责的成员；可由需求验收人兼任。
