# 试点是否引入 OpenViking，团队记忆如何被确认、纠正和使用？

## Question

基于源码调查和团队实际重复工作，决定试点是否需要 OpenViking、先覆盖哪些信息。明确个人记忆、候选经验、经确认的团队知识和正式规格的区别；确定共享责任人、引用来源、失效/撤回方式，以及记忆与 Git 中 Skills 的权威关系。选择可衡量的收益及停止采用条件。

## Context

2026-10-10 用户已选择 [OpenSpec 原生结构＋薄导航、按需求补知识](05-document-maintenance.md)。本票据判断记忆工具是否带来额外协作收益；不以新建知识平台作为这条路线的默认前提，也不因已选薄导航就推定用户否决 OpenViking。
