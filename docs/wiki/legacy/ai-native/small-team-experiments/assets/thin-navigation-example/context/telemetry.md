# 遥测上下文入口（演示）

这是导航样例，以下是待试点核对的资料种类，不是实际实现路径或验证结果。

| 读者需要什么 | 实际接入时链接到哪里 |
| --- | --- |
| 网关接收、设备管理、查询 API | 对应代码仓的真实目录、接口定义；每项只保留一个入口 |
| 消息契约 | 已存在的消息格式或 schema 源文件 |
| 验证环境 | 已存在的环境启动和版本固定说明 |
| 故障排查 | 既有 runbook，而非在功能页复制步骤 |
| PR、独立审查和集成证据 | 已有 Delivery Issue / Review / Evidence 的固定版本入口 |

接入时把已确认的入口填入 catalog；不因本演示增加另一套架构文档、运行手册或证据表。
