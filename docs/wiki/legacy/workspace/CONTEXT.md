# Ming IoT 平台协作语境

本词汇表记录仓库组织与平台交付讨论中已经澄清的项目用语。

## Language

**平台交付版本**：向客户承诺的一组相互兼容的平台组成部分版本。各组成部分可以独立部署，该组合共同界定一次平台交付的版本范围。

**Insight 体系**：为 AI Native 开发组织项目知识并提供上下文导航的文档体系。其方法与工具可供多个代码仓复用。

**MQTT 接入组件**：面向多个平台复用、独立维护版本的设备接入组件。

**迁移来源资料**：来自 ming-iot-rd-docs、iot-doc 和 ai-native，供 Ming IoT 筛选、核对和提炼的实验及历史材料。保留这些材料不代表采纳其中的设计、流程或代理指令。

**现行项目文档**：Ming IoT 明确采用且适用范围清楚的项目依据，并区分当前实现与已确认的后续目标。文件所在的旧目录或旧文档自称的权威地位，不构成现行文档的认定依据。
