## 目标和不变项

让实际跨服务事件生产与消费改用 Kafka，并能证明原有调用职责得到承接。已核实的现状与风险只在主规格维护；本 Patch 保存拟改变的规则、决定、步骤和证据导航。

本次环境准备不改变通知昵称规则。外部设备 MQTT、HTTP/gRPC API 与进程内分发不因名称中含事件就自动换成 Kafka；它们是否受具体迁移改动影响，须通过调用清单核对。旧环境和数据持续保留。
